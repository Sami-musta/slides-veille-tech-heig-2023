Le tirage est prêt !

Chaque personne a son cadeau mystère. Choisissez comment découvrir les résultats.

À chacun son tour 🤫

Passez le téléphone. Chacun touche uniquement son prénom, regarde son résultat, puis masque l’écran.

🔐 Après consultation, le prénom est marqué comme « Vu » pour éviter de révéler le résultat à quelqu’un d’autre.

Un lien privé pour chacun 💌

Envoie chaque invitation dans une conversation privée (par exemple sur WhatsApp). La personne verra seulement à qui elle doit offrir un cadeau.

🌐Pour créer des liens fonctionnant sur différents téléphones, publie d’abord ce site en ligne (voir le guide fourni). En attendant, tu peux télécharger les cartes individuelles ci-dessous.

⚠️ Ne partage pas les liens dans le groupe familial : chacun doit recevoir seulement le sien. Les résultats restent sur ton appareil et dans les invitations privées.

Aucun compte requis. Les données du tirage sont enregistrées uniquement dans ce navigateur.
